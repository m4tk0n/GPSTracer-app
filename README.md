# GPSTracker

Android aplikace pro záznam trasy, měření vzdálenosti, statistiky a sdílení dat.

## Funkce
- zobrazení aktuální pozice na mapě
- záznam trasy
- měření času a ujeté vzdálenosti
- statistiky trasy
- kompas a orientace
- práce bez internetu
- synchronizace dat se serverem
- sdílení polohy nebo trasy

## Technologie
- Kotlin
- Jetpack Compose
- OpenStreetMap / MapLibre
- Android GPS a lokace
- Room Database
- Retrofit / API komunikace
- PHP + MySQL na serveru

## Cíl projektu
Aplikace má sloužit pro:
- plánování tras
- záznam jízd a výletů
- statistiky a zhodnocení trasy
- sdílení aktuální polohy a záznamu trasy

## Vývoj
Tento projekt je rozdělen do postupných fází:
1. základní aplikace a mapa
2. GPS záznam a statistiky
3. práci bez internetu
4. synchronizace se serverem
5. sdílení polohy a tras
6. offline mapové podklady

## Poznámka
Tento projekt se vyvíjí postupně ve fázích a je optimalizovaný pro práci na pomalejším stroji.
